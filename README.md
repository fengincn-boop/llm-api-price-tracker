# llm-api-price-tracker

Daily auto-updated LLM API pricing, multi-channel arbitrage spreads, and F.A.R.E. benchmarks.

This repository automatically fetches the latest open static JSON feed from `https://llmfare.com/api/prices.json` every day via GitHub Actions and updates `PRICES.md`.

See live tables in [PRICES.md](./PRICES.md) or interactive F.A.R.E. scatter charts & subscription vs API calculators on [LLMFare.com](https://llmfare.com/en/).
